# Magnitogorsk — la préparation

**Ce que l'on fait, au présent.** Un document de ce dossier ne compare rien, ne justifie rien, ne
liste aucune option écartée : **il dit ce qui est joué.**

| Où | Quoi |
|---|---|
| **`preparation/magnitogorsk/`** | **l'état courant.** Rien à interpréter |
| `travail/magnitogorsk/` | le cheminement — comment on y est arrivé |
| **les messages de commit** | **pourquoi on a changé d'avis.** Git versionne, le texte n'a pas à le porter |
| `src/prep-magnitogorsk/` | **les questions ouvertes**, et elles n'existent qu'à cet endroit |

> **Aucun écart n'est écrit** — ni avec le scénario du commerce, ni avec les aides non officielles.
> **On ne mène pas la source : on mène ceci.** Les documents disent le fait, jamais ce qu'il
> remplace.
