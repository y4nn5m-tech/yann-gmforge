# Magnitogorsk — notes de travail

Hors de la chaîne, et c'est le but. `build.py` ne lit que `src/` : rien ici n'est compilé, paginé,
contrôlé ni publié. Ces notes cherchent l'exhaustivité, pas la mise en page — elles peuvent faire
quarante pages, se contredire d'un fichier à l'autre le temps qu'une question se tranche, et
reprendre la source mot pour mot quand c'est utile.

**Les documents finaux se tirent d'ici, à la fin**, dans `src/`, et c'est là seulement que la
charte, les cinq couleurs et les contrôles s'appliquent.
